One original sentence, written by the program in `main.ts` to
`/output/entry.txt` (program/v1 harness, Node 22, standard library only).

## The line (100 chars)

> When I opened the fridge door, its hum changed key, like a choir clearing its throat for one singer.

## Why this line

- **Small moment of wonder:** opening the fridge — an act done a dozen times a day, unnoticed.
- **Fresh angle:** the surprise is in the phrasing itself — a compressor's pitch shift heard as a choir clearing its throat for a single singer. Nobody expects choral manners from an appliance.
- **Lands in one read:** the action opens, the change follows, the image lands on the final words.
- **Grounded in something real:** a fridge compressor genuinely shifts pitch when the door opens and the cold air spills out.
- **Tight:** 100 characters, one sentence, every word working — no filler, no worn phrase.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

The program self-checks the gate before writing: 1–200 characters, not only
whitespace, exactly one sentence — and fails loudly instead of handing in a
bad entry. Verified: the line is 100 characters, one sentence, valid UTF-8,
byte-identical across two runs.
